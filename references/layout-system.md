# 菜单海报排版秩序系统

## 路由

- 新构图或更换版式：先读 [layout-templates.md](layout-templates.md)，按主体负空间选择模板；可从 [layout-template-library.json](layout-template-library.json) 读取参数。
- 已获用户认可的版式：保留骨架，只改本次指定的组件、字号或间距。
- 模板数字是起点；实际字形包围框、主体轮廓和最终展示尺寸决定落点。

## 1. 分组与主次

默认 1–2 个主要文字组：标题组、信息组。它们可位于上方、侧方或下方，不强制“上标题、下说明”。

主标题、对应英文与短副标题构成同一语义组；整组定位后再细调组内间距。标签栏即使有三列，也属于同一个重复组件。日期、英文品类、角标等可并入相邻主组；没有真实信息就不添加。

侧边竖排短句为可选组件。用户在本轮明确删除了奶茶两侧短句与寿司右上短句；已确认的这两类布局默认关闭侧注。其他模板只有在具有独立信息价值且留白适合时才使用。

## 2. 对齐与重复

- 主要文字组通常使用 1–2 条主轴。每组共享左边线、中心轴或右边线。
- 左、中、右对齐分别使用相同的 `position.x` 与 `align: left|center|right`。
- 次要组件可使用自身网格：例如三列标签用等宽分栏与等中心距；不得为了满足“两条轴”而把分栏取消。
- 重复组件同字号、同颜色、同符号体系、同一行顶线或基线。
- 不强制左右成对、不强制角标；重复原则适用于已经选择的同类组件。
- 英文应紧邻对应中文。全大写英文可使用轻微字距；连贯中文标题不人为拉宽到松散。

## 3. 字号与实际字形

以画布 1086×1448 为当前工作基准；标准字号建议见模板参考。JSON 的 `font_size = 像素字号 / H`，H 为实际画布高度。

字号不是可见墨迹高度。自言自画体字面较疏，不能只比较 em 数字；先渲染查看汉字实际高度与整行宽度，再调整。主标题应明显先于辅助文字被读到；主标题对说明文字通常为 2.8–4 倍。相邻语义层级可使用相同字号，不强制每一级都至少差 1.35 倍。

用户说“整体大 2 号”且没有印刷单位时，本项目以已认可版本的每个文字块实际像素字号统一 +2px 执行，并记录基准；不叠加到未确认的实验版。不能把中文字号序列中的“二号”当作这里的增量。

## 4. 间距：以可见墨迹为准

所有间距指相邻墨迹包围框之间的净空，不是两个 `position.y` 的差值。渲染器的字体基线、上升部和内部留白均需纳入计算。

- 主标题两行：净空建议 0.15–0.30 倍主标题实际可见字高。
- 中文标题与英文译名：净空建议 0.18–0.30 倍主标题实际可见字高。
- 标题与独立卖点：建议 0.35–0.55 倍主标题实际可见字高。
- 标签与其说明：建议 0.35–0.65 倍标签实际可见字高。
- 组间距原则上为相邻组内距的 2–3 倍以上；主体可以自然分隔上下组。
- 减少碰撞时先移动相邻行几像素或微缩字号。不得未经需要把同一组拆到画面两端。

这些范围是观察与调参起点，非所有字体必须达到的固定数值；用户已认可的亲密关系优先保留。

## 5. 主体与文字安全区

### 主体占比与缩放

- 分母统一为整张画布 W、H。以完整商品的边界框 w、h 记录 width_ratio=w/W、height_ratio=h/H；新建稿默认 max(width_ratio,height_ratio)=0.50–0.55。
- 不把面积百分比、宽高百分比和相对缩放百分比混用。例如高占画布 60% 的主体缩小 15%，新高度为 60%×0.85=51%，不是 45%。
- 用户指定对认可稿缩小 10%–20% 时，前后宽、高比均应在 0.80–0.90，优先尝试 0.85；以用户这次相对调整为准，不额外强制缩到新建默认值。
- 图像生成工具的尺寸指令可能存在偏差；用颜色分割辅助测量并目视核对完整轮廓，记录测量方法与容差。不得把生成目标写成实测结果。
- 只统计商品、装饰食材与自身容器；背景、投影和文字不计入。枝条主体的核心果实簇与触边支撑枝条分别记录。
- 缩放采用等比缩放，保持视觉中心；文字字号独立保留。原有安全区可保留为保守禁入区，也可根据新轮廓更新。
- 如果是生成式编辑而非纯几何变换，应复核细节与比例，交付时不能声称像素完全不变。

### 安全区

- 左右安全边距通常为 W 的 8%，上下至少 H 的 3%；模板可在 6%–10% 左右边距内适配。
- 用 `subject_exclusion_zone` 覆盖主体及所需净空，特别包括奶油尖、果梗、杯口与叶尖。
- 文字墨迹框不得与其他文字框或主体禁入区相交。
- 主体与文字建议保留 H 的 1%–1.5% 净空；精细轮廓可目视确认。
- 不规则枝条若用整幅矩形会误封大片留白，应分区规划并核对实际轮廓；当前脚本仅检查声明的单矩形，不能代替目视检查。
- 树枝可自然触边；核心商品完整展示。
- 留白允许保持空白，不是待填满的区域。

空间确实不足时：先小幅修正相邻行，再删减无必要的次要信息、缩短文案或整体移动文字组。文字不得小到不可读。

## 6. 字体、语言与字形

- 自言自画体：主标题、中文卖点和重点标签；亦可用于匹配气质的英文或繁体。
- 阅宋：辅助说明、英文译名、日期和参数等小字。
- 全图最多两种字体。主标题组中的主要中文保持同一简繁体系；说明可独立用简体。
- 保持字体共享基线；禁止逐字包围框顶部对齐，以免标点和“一”上浮。
- 检查当前文案字符是否有墨迹。发现字体缺字时优先使用该字体支持的同义字、简体或改写，不得留下空字位。
- 默认不使用逐字旋转、缩放或随机坐标。
- 参考中的错列标题可按 2–4 个词段整体排成有意的列关系；需选择对应模板，不能随机挪单字。
- 禁止复制参考品牌、认证、价格、日期或无意义英文。信息须由用户提供或可由主体合理确定。

## 7. 候选与迭代

新建排版时选择 2–3 个结构有明显差异且适合当前负空间的模板候选；差异应来自标题方向、信息区位置或组件关系，而不只是左右挪动。

连续作品避免机械复用骨架；用户已经认可并要求保留的同款骨架可复用。微调任务只修改指定参数，不为满足候选数量重做版式。

## 8. 实际检查

渲染后执行：

```powershell
python scripts/audit_typography.py --layout <layout.json> --out <audit.json>
```

脚本检查实际墨迹框、文字碰撞、主体禁入矩形、画布越界和空白字形，并输出每块的实际像素字号。它不能识别所有缺字方框，也不能判断亲密关系和审美；必须配合最终预览检查。不得用主观评分代替碰撞检查。
